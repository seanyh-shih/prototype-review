Classify 5 Hair Lengths Instantly with Structured AI Output

The Hair Length Detection API is a hair analysis API that classifies a person's hair length from one photo. It sorts each detection into one of five stages, from above the ears to long hair. Hair care brands, salons, and retailers use that result to drive product recommendations and consultations.

One API for Five Hair Length Results You Can Act On

Upload a front facing photo and the API returns the detected hair length as a single named value. Everything runs over standard REST, so the result drops straight into your recommendation logic.

  • Returns a named hair length result based on five length categories
  • Accepts a JPG or PNG photo uploaded through the file endpoint
  • Asynchronous task model with a documented polling endpoint

Hair Length Classification in Every Response

Every detection resolves to a named stage, so your catalog logic always receives a value it can map.

  • Five stages: above the ears, ear length, short hair, above chest, and long hair
  • Supports “or longer” results when the exact result falls between two lengths
  • Returns a simple value your app can use for recommendation logic

How to Use the Hair Length Detection API

Three calls take you from a user photo to a hair length your app can act on.

STEP 1

Upload the Photo

Send a photo to the file endpoint and keep the file ID it returns.

STEP 2

Start the Detection

Post that file ID to the hair length detection endpoint and store the task ID.

STEP 3

Read the Result

Poll the task endpoint until it completes, then read the hair length result.

Hair Length Detection API FAQs

It is an API that reads a photo and returns the person’s hair length as a named category instead of a measurement in centimetres. The YouCam Hair Length Detection API sorts each photo into one of five stages, from above the ears to long hair, and returns that value as structured JSON. Brands use it to personalize hair care recommendations and consultations.

Five: above the ears, ear length, short hair, above chest, and long hair. The API also returns boundary values, such as ear length or longer, when a length sits on the edge between two stages. Treat those boundary values as a valid result and map them in your recommendation logic like any other.

“Ear length or longer” is one of the documented hair length results returned by the API. Your application can treat it as a valid result and map it to the appropriate recommendation logic.

Send a JPG or PNG under 10MB, at least 320px and at most 4096px on each side. The full face must be visible and within 10 degrees of straight forward, with hair worn down and falling over the chest. Images larger than 1080px on either dimension are resized automatically before detection.

It is asynchronous. You post the uploaded file to the hair length detection endpoint, receive a task ID, then poll the task endpoint until the status leaves running. Your app can keep the interface responsive while the task completes in the background.

The API returns a named error code rather than a low confidence result. Codes cover insufficient lighting, an invalid face angle, an invalid or out of boundary face position, a face that is too small, and an image below the minimum size. Map each code to a specific retake prompt so the user knows what to change.
