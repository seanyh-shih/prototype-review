# prototype-review

內部設計 review 用的 prototype 展示櫃。每個專案是一個獨立資料夾，直接用瀏覽器開啟（或透過 GitHub Pages 網址瀏覽）。

- 專案清單：`index.html`
- 路徑規則：`<品牌>/<專案名>/index.html`，例如 `yco/API_AI_Image_Extender/`
- 製作與修改都在本地端進行，需要 review 時才上傳；同一專案重複上傳會覆蓋原路徑，網址不變。
- 這裡只放可直接瀏覽的成品（`index.html`、`style.css`、`script.js`、`assets/`），不放規範文件與內部筆記。
