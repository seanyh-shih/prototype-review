# Topbanner · slider（圖片輪播）【草稿，尚未實測】

來源：SECTIONS.md Section 01 格式 3。共用規範見上層 `SPEC.md`。**目前只有規範，沒有樣式與腳本**，實作時需先實測。

## 已確認的行為

- 3～4 張圖片做幻燈片輪播。表單預設 3 組，可用「＋」增加，不設上限（已知專案最多到 4 組）。
- **自動輪播**：不需要使用者操作，計時器自動切換下一組圖片＋文字。畫面上**沒有導覽點（dots）與左右箭頭**。
- 圖片切換是**淡入淡出**，`opacity` 過渡 **0.5 秒、linear**。
- 前景的「prompt 提示詞」文字框有**逐字輸入（打字機）效果**，實測速度約每秒 1 個字元。
- **主標題與副標題固定不動**，只有「prompt 提示詞」文字框會隨輪播改變。
- prompt 提示框位於 CTA 上方、帶邊框的淺色框、斜體文字，視為這個格式 CTA 組成的一部分。
- 輪播圖片檔名用流水號（01、02、03…）。

## 素材

每組輪播：3 個尺寸各 1 張圖片，加 1 段 prompt 文字。命名範例：`topbanner-slide-01-dt.jpg`。

- guideline 說「會隨 slider 改變的文字」具體是哪一段（目前依實測當作 prompt 提示框）。
